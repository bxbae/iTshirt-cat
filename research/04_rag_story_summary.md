# 맞춤 동화 생성(RAG)과 타입캐스트 낭독: 요약

## 제안
아이가 좋아하는 동화 3~5편을 고르면, 그 동화들의 분위기·구조·어휘 수준을 검색(RAG)해 **새 동화를 AI가 만들고**, **타입캐스트(Typecast) TTS**가 읽어 준다. 기획서의 "AI 오리지널 + 퍼블릭 도메인" 전략을 아이 한 명에게 맞춘 콘텐츠로 확장하는 기능이다. (출처: 멘토링 자료 주제2의 "RAG 활용 (제안)")

## 사용자 흐름
동화 탭 '나만의 동화 만들기' → 좋아하는 동화 3~5편 선택 → 조건 선택(주제·길이·분위기·잠자리용 여부) → 생성(진행 표시, 완료 알림) → **부모 미리보기·승인** → 낭독 뷰어 → '만든 동화' 보관·신고. 입력은 선택형 위주로 하고 자유 입력은 MVP에서 제외한다.

## RAG 구조
- **검색 대상**: 자체 오리지널과 권리가 확인된 퍼블릭 도메인 동화만 사용한다(번역본·편집본 권리는 별도 확인). 시판 동화는 코퍼스에 넣지 않고, 선택 화면도 우리 라이브러리 안으로 한정한다.
- **가공**: 장면(페이지) 단위로 나눠 월령·주제·분위기·안전 등급 등 메타데이터를 붙이고, 임베딩해 PostgreSQL 벡터 확장(pgvector)에 저장한다. 동화마다 스타일 프로필(주제, 구조, 어조, 결말)도 뽑아 둔다.
- **취향 프로필**: 고른 동화들의 프로필을 합친다. 저장하는 것은 선택한 콘텐츠 ID와 태그뿐이고 부모가 초기화할 수 있다.
- **검색**: 월령·안전 등급·검수 상태 필터를 거친 뒤 벡터+메타데이터 하이브리드로 요소를 고른다.
- **생성**: 아웃라인 → 본문 → 안전 검사 → 화자·문장 분할 → 낭독 합성 → (선택) 삽화. 원문 문장은 베끼지 않고 분위기와 구조만 참고하도록 지시한다.
- **월령별 규칙(제안값)**: 0~12개월은 3~5쪽에 쪽당 1문장, 37~60개월은 8~12쪽에 쪽당 3~5문장 등으로 조정한다. 근거가 있는 수치가 아니라 인터뷰와 시범 제작에서 검증해야 한다.
- **삽화**: 처음에는 기존 삽화 조합 또는 오디오 전용으로 시작하고, 즉석 이미지 생성은 검수 체계가 갖춰진 뒤에 도입한다.

## 안전·품질
기획서의 "모든 콘텐츠는 사람 검수 후 공개" 원칙과 즉석 생성이 충돌한다. 세 가지 안 중에서 정해야 한다.

| 안 | 방식 | 특징 |
|---|---|---|
| ① 사전 검수형 | 운영자가 검수한 템플릿 중에서 매칭 | 가장 안전, 개인화 낮음 |
| ② 검수 대기열형 | 요청 → 자동 검사 → 사람 검수 → 알림 | 원칙 유지, 대기와 인력 필요 |
| ③ 자동 검사+부모 승인형 | 즉시 재생, 사후 신고·샘플 검수 | 원칙 완화, 위험 가장 큼 |

자동 검사는 무서운 표현, 편견, 실존 브랜드·캐릭터, 원문 유사도, 월령 어휘, 아이 개인정보, 건강 정보 단정을 확인한다. 신고가 들어오면 즉시 비공개 처리하고, 화면에 'AI가 만든 이야기'임을 표시한다.

## 타입캐스트 낭독
- **확인된 사양**(공식 문서 검색 요약): 감정 프리셋과 문맥 기반 스마트 모드, 템포·피치·음량 조절, WAV/MP3, 스트리밍, **단어·문자 단위 타임스탬프**. 타임스탬프는 기획서의 문장 하이라이트와 StoryPage 오디오 타이밍에 쓸 수 있다.
- **낭독 설계**: 내레이터 1명과 등장인물 최대 2명, 잠자리용은 속삭임 계열 감정과 느린 템포, 고유명사 발음 사전을 둔다.
- **파이프라인**: 문장 분할 → 화자·감정 태깅 → 문장 단위 합성 → 후처리 → 스토리지·CDN 저장. 한 번 합성한 파일을 재사용해 비용을 줄이고, API 키는 서버에만 둔다.
- **확인하지 못한 것(서면 확인 필요)**: 오프라인 저장·재배포 허용 여부, 어린이 콘텐츠 조건, 보이스 이용 범위, 요금과 호출 제한.

## 기술 변경
엔티티 5개(StoryChunk, StoryStyleProfile, GenerationRequest, GeneratedStory, NarrationAsset)와 생성·승인·신고·낭독 API를 추가한다. 관리자에는 검수 대기열, 코퍼스 라이선스 관리, 신고 처리 화면이 필요하다. 생성 이야기는 해당 사용자에게만 보이는 비공개 콘텐츠로 시작한다.

## 단계별 도입 (권장)
1. **MVP**: 선택 이력 기반 취향 추천(검색만), 사전 제작 콘텐츠에 타입캐스트 낭독 적용
2. 요청형 생성 + 검수 대기열
3. 즉시 생성(자동 검사+부모 승인), 삽화 즉석 생성 검토

## 주요 위험
저작권, 부적절한 생성물, 원문 유사, 생성·TTS 비용, 대기 시간, TTS 약관 제한, 아이 개인정보 이슈. 시장조사에서는 가설 H6~H8(맞춤 생성 관심, 확인·검수 방식 선호, AI 낭독 수용)을 인터뷰 6-2절과 설문 Part I로 확인한다.

## 결정 필요 사항
MVP 포함 범위, 검수 방식 ①②③, 코퍼스 작품 선정, 삽화 방식, 타입캐스트 계약 조건과 대체 TTS, 생성 횟수 제한과 수익 모델, 이야기에 아이 이름을 넣는 기능의 허용 여부
